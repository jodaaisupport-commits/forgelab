# ForgeLab AI Model Studio

Deutsche, responsive Frontend-Simulation eines AI-Model-Studios ohne Framework. Starte `index.html` über einen lokalen Webserver. Authentifizierung, Daten und Demo-Status verwenden die verfügbare Miniapp-Speicher-API; produktive Konten, Tokens und Inferenz benötigen ein abgesichertes Backend.

Der ZIP-Export ist bewusst unabhängig von Popups und erstellt auch bei fehlenden Dateien ein gültiges Archiv.
